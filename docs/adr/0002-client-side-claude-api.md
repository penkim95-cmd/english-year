# 0002. 서버 없이 기기에서 학습자 키로 Claude API를 호출한다

- 상태: 채택
- 날짜: 2026-10-23

## 배경

AI 대화·평가·첨삭에는 대형 언어 모델이 필요합니다. 이 앱은 한 사람이 자기 휴대폰에서 쓰는 개인용이고, 서버를 운영·비용 부담·보안 관리할 주체가 없습니다.
초기 버전은 claude.ai 아티팩트 안에서 돌아가며 그 환경의 AI 기능을 썼지만, 그 방식은 claude.ai 안에서만 동작하고 홈 화면 앱으로 설치할 수 없었습니다.

## 결정

- 학습자가 Anthropic Console에서 만든 API 키를 앱 설정에 넣고, 앱이 공식 SDK(`@anthropic-ai/sdk`)로 `api.anthropic.com`을 직접 호출합니다(`dangerouslyAllowBrowser: true`).
- 키는 그 기기의 `localStorage`에만 저장하고 백업 파일에 넣지 않습니다.
- CSP `connect-src`를 `'self'`와 `https://api.anthropic.com`으로 제한해, 혹시 스크립트가 주입되더라도 키를 다른 곳으로 보낼 수 없게 합니다.
- 기본 모델은 Claude Opus 5이고, 설정에서 Sonnet 5·Haiku 4.5로 바꿔 비용을 줄일 수 있습니다.

## 검토한 다른 방법

| 방법                           | 버리거나 미룬 이유                                          |
| ------------------------------ | ----------------------------------------------------------- |
| 자체 프록시 서버               | 운영·비용·인증을 맡을 주체가 없음. 개인용 앱에는 과함       |
| claude.ai 아티팩트 런타임 유지 | 홈 화면 설치·오프라인 불가                                  |
| 기기 안 로컬 모델              | 아이폰 브라우저에서 회화 품질이 나오는 모델을 돌리기 어려움 |

## 결과

- 좋은 점: 서버가 없어 운영 비용이 0이고, 대화 내용은 기기와 Anthropic 사이에서만 오갑니다.
- 나쁜 점: 키가 기기에 평문으로 저장됩니다. 그래서 **다른 사람에게 배포하는 용도로는 이 방식을 쓰지 않습니다.** 여러 사용자를 받으려면 서버에서 키를 보관하는 프록시가 필요하고, 그때 이 ADR을 대체합니다.
- 위험 줄이기: 앱 전용 키, 월 사용 한도, 분실 시 키 폐기, 신뢰하지 않는 페이지와 같은 출처에 올리지 않기([SECURITY.md](../../SECURITY.md)).
