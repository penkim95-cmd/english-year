# 0004. 과정 콘텐츠를 코드와 분리된 JSON으로 둔다

- 상태: 채택
- 날짜: 2026-10-23

## 배경

52주 레슨(주마다 포인트 3개·예문·따라 말하기·팁), 단어 780개, 슬랭 82개, 단계 정리 학습지가 코드보다 훨씬 큽니다. 첫 버전에서는 이것들이 자바스크립트 배열 리터럴로 코드 사이에 섞여 있어서, 콘텐츠를 고치다 코드를 깨뜨리기 쉬웠습니다.

## 결정

- 콘텐츠는 `src/data/*.json`에 둡니다. 형식은 `src/types.ts`의 타입으로 정의하고 `curriculum.ts`에서 한 번만 타입을 붙여 내보냅니다.
- 코드로 표현하는 편이 나은 정의(4단계 일정과 하루 할 일, AI 친구의 성격 프롬프트, 상황별 미션)는 `curriculum.ts`에 둡니다.
- 콘텐츠의 일관성은 테스트로 지킵니다: 52주 모두 존재, 주마다 포인트 3개·단어 15개(중복 없음), 단계 주차가 빈틈없이 이어짐, 모든 주의 자동 학습지가 정답으로 풀림.
- 콘텐츠 JSON은 Prettier 대상에서 빼서, 콘텐츠 수정 diff가 서식 변경에 묻히지 않게 합니다.

## 결과

- 좋은 점: 콘텐츠만 고치는 기여가 코드 지식 없이 가능하고, 잘못된 수정은 CI 테스트가 잡습니다.
- 나쁜 점: JSON은 빌드 때 번들에 포함되어 첫 로드 크기가 늘어납니다(앱 코드와 합쳐 gzip 약 85KB). 서비스 워커가 캐시하므로 두 번째부터는 영향이 없습니다.
