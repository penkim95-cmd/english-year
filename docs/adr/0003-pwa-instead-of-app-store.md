# 0003. App Store 앱 대신 설치형 PWA로 배포한다

- 상태: 채택
- 날짜: 2026-10-23

## 배경

요구는 "아이폰에 한 번 설치하면 업데이트 말고는 다시 설치하지 않는 앱"이었습니다. 필요한 기기 기능은 마이크(음성 인식)와 스피커(음성 합성)입니다.
무료 Apple 개발자 계정으로 직접 설치한 네이티브 앱은 7일마다 다시 서명해야 하고, 그걸 피하려면 연 99달러 개발자 프로그램이 필요합니다.

## 결정

- Safari의 '홈 화면에 추가'로 설치하는 PWA로 배포합니다(전체 화면, 홈 화면 아이콘, 오프라인).
- 서비스 워커는 빌드 때 생성합니다(`build/pwa.ts`). 내보낸 파일 전체를 미리 캐시하고, 캐시 이름에 내용 해시를 넣어 배포마다 한 번 갱신됩니다. 앱 화면은 네트워크 우선, 해시가 붙은 파일·글꼴은 캐시 우선입니다.
- 새 버전이 적용되면 입력 중이 아닐 때 한 번 자동 새로고침합니다.
- `vite-plugin-pwa` 같은 플러그인 대신 직접 작성했습니다. 필요한 기능이 미리 캐시·버전 갱신 두 가지뿐이라 100줄 남짓이고, CSP 삽입과 한곳에 두는 편이 읽기 쉽습니다.

## 결과

- 좋은 점: 재서명·심사·비용이 없고, 배포하면 설치된 앱이 알아서 갱신됩니다. 같은 코드가 데스크톱 브라우저에서도 동작합니다.
- 나쁜 점: iOS 웹앱은 백그라운드 실행·푸시 알림이 제한되고, 음성 인식 품질이 Safari 구현에 달려 있습니다. 음성 인식이 안 되는 경우를 위해 키보드 받아쓰기 자동 전송을 함께 둡니다.
- 다시 검토할 때: 알림이 꼭 필요해지거나 App Store 배포가 목표가 되면 Capacitor 등으로 같은 웹 코드를 감싸는 방안을 봅니다.
